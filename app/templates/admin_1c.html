Як підключити

  1. Відкрийте 1С Конфігуратор → Загальні модулі → СинхронизацияСахары
  2. Замініть весь вміст модуля кодом з вкладки Загальний модуль (кнопка "Копіювати")
  3. Перевірте властивості модуля: Сервер = Да, Клиент = Нет
  4. Регламентне завдання → ИмяМетода = СинхронизацияСахары.ОтправитьНаСайт
  5. Збережіть і оновіть конфігурацію бази даних
